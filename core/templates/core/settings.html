iPhone Shortcut setup

  1. Create a capture token above and copy it.
  2. In the Shortcuts app, add action Get Text from Share Sheet (or Ask for Text for Siri capture).
  3. Add action Get Contents of URL: POST to https://gtd.sudipto.dev/api/capture, header Authorization: Bearer <token>, JSON body {"title": Shortcut Input}.
  4. Add action Show Notification to confirm capture.
  5. Enable "Show in Share Sheet" and add a Siri phrase if you want voice capture.
